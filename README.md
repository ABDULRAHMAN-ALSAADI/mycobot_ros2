# MyCobot 280 RViz Simulation (ROS 2 Jazzy)

This repository contains a simulation of the **Elephant Robotics MyCobot 280** robot arm using **ROS 2 Jazzy** on **Ubuntu**. The robot is visualized in **RViz** for motion and kinematic testing without physical hardware.

## Features
- MyCobot 280 robot arm simulation
- RViz visualization
- ROS 2 Jazzy support

## Environment
- Ubuntu
- ROS 2 Jazzy
- Elephant Robotics MyCobot 280
- RViz
